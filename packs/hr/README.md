# HR pack

Starter workflows for hiring and people-ops at a small business.

## Workflows
- `cv-triage` — inbound CVs go to a workspace inbox; agent extracts via
  vision, scores against open roles in workflow memory, pings the
  hiring manager in Slack.
- `new-hire-welcome` — manual trigger after an offer's signed; drafts
  the welcome email + Slack intro post for review.

## Tasks
- `tasks/new-hire-onboarding` — multi-phase: welcome email →
  account-setup checklist → human-gated first-week check-in.
